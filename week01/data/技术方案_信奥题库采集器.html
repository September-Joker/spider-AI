信奥题库采集器：
你的第一个工程化 Python 项目

这个项目不是练习语法的 demo，而是按真实生产方式组织的：分层架构、限速重试、数据清洗、 数据库去重、大模型标注。跑通它，你就把 Q1 要学的爬虫工程化和 LLM API 两大块都过了一遍， 同时手里有了一个能直接放进 GitHub 的作品集。

📦 依赖只有 requests，零数据库安装 🗄 数据存 SQLite 单文件 🤖 LLM 标注可选，不配 Key 也能跑 📚 数据源 Codeforces + AtCoder 官方/社区公开 API

1五分钟跑起来

解压项目包后，在 oi_collector 目录里依次执行：

# 1. 安装依赖（建议先建虚拟环境）
pip install -r requirements.txt

# 2. 采集 Codeforces 前 20 道题（先小量，礼貌爬取）
python main.py fetch --source codeforces --limit 20

# 3. 再采 AtCoder
python main.py fetch --source atcoder --limit 20

# 4. 看看库里有什么 / 统计
python main.py list --limit 10
python main.py stats

# 5.（可选）配大模型 Key 后，让 AI 标注知识点和适合年级
set LLM_API_KEY=sk-xxx        # Windows
# export LLM_API_KEY="sk-xxx"     # Mac/Linux
python main.py tag --limit 10
运行预期：采集时你会看到日志输出，可能出现个别「请求失败→重试」的警告后仍然成功—— 这就是指数退避重试在真实网络环境下工作的样子，不是 bug。重复运行同一采集命令， 你会看到「新增 0，更新 N」，说明去重生效了。

4边用边学：6 个核心工程概念

不用先啃书。跑通项目后，带着问题回到对应文件看代码，每个概念都有真实上下文。

① 分层与适配 每个网站字段命名都不同（name vs title），_normalize() 把它们统一成内部格式。 以后加牛客，只写一个新文件，其他层一行不改。
② 礼貌爬取与合规 REQUEST_DELAY=2 秒限速、UA 写明用途、遵守 robots.txt。 这不是可选项——这是你作为工程师的职业底线。
③ 面向失败设计 网络会超时、接口会 500、结构会变。重试机制和防御性解析（.get() 而非 [] 取值） 让程序「坏一部分也不崩」。
④ upsert 去重 靠数据库 UNIQUE 约束 + 插入冲突转更新，跑 100 次也不会出现重复题目。 这是所有爬虫数据落地的标准套路。
⑤ LLM 结构化输出 Prompt 里明确要求「只输出 JSON」，程序再 json.loads 解析。 AI 功能的核心不是调 API，是把模型输出变成程序能用的结构化数据。
⑥ 增强而非依赖 不配 Key 采集照常工作；LLM 调用失败只警告不中断。 AI 是锦上添花，系统的主链路永远要能独立运行。

5六周拆解（对应路线图 Q1）

每周 8–10 小时。重点不是读代码，是改代码——每个改动都 commit 到 GitHub。

1

跑通 + 读懂

安装运行四个命令；对照文件结构表，把每个文件通读一遍，在不懂的行写注释问我。注册 GitHub，建仓库把代码推上去（.gitignore 忽略 data/oi.db）。

2

改造清洗与存储

给 clean.py 加规则：标题含「测试/广告」的丢弃；给 storage.py 加一个 search(keyword) 函数按标题关键词查题，并接到 main.py 新命令 find。

3

加第一个新数据源

照着 atcoder.py，新写一个采集器（建议 AtCoder 难度接口 problem-models.json，把难度补全）， 注册进 FETCHERS。这一周结束你就有了「扩展系统」的能力。

4

接入 LLM

申请 DeepSeek API Key（充值 10 元够用很久），跑通 tag。 然后改 Prompt：让模型额外输出「这道题适合讲什么知识点」「推荐给几年级」，观察输出质量差异。

5

导出教学产物

加 export 命令：按知识点/难度筛 10 道题，生成 Markdown 格式的「本周练习卷」。 打印出来，真的发给你的学生用一次。

6

异步提速 + 定时

把 base.py 的同步 requests 改成 aiohttp + asyncio（配合信号量控制并发， 别超过 3）；再用 Windows 任务计划程序设成每周自动跑。写一篇 README 记录踩坑——这就是你的第一篇技术内容。

6之后的扩展路线（通向 Q2）

  • Playwright 解锁洛谷：浏览器渲染 + 等待动态内容 + Cookie，把 luogu.py 启用——这是你第一次接触反爬对抗。
  • Streamlit Web 界面：给题库加搜索/筛选页面，100 行代码出一个能用的网站，部署到云服务器。
  • 通向 Q2 的关键一跃：把题目标题、标签、你的教案一起喂进向量库（RAG），实现「我下周想讲贪心，给我 10 道难度递进的题+讲解思路」——这就是 AI 备课机器人的内核。
作品集意识：每个阶段完成后，在 GitHub README 里加一段「我做了什么、解决了什么问题、踩了什么坑」。 面试官和合作方看的不是代码量，是你解决问题的完整叙事。

7合规红线（务必遵守）

  • 只采集公开数据，尊重每个网站的 robots.txt 和服务条款；Codeforces / AtCoder Problems 均提供公开接口，优先使用接口而非爬页面。
  • 限速不低于 2 秒/次，并发不超过 3；服务器返回错误或封禁信号时立即停止。
  • 不采集、不存储任何个人信息；抓取的数据仅用于个人教学与学习，不公开传播原始数据集。
  • 不绕过付费墙、不破解需要登录的内容；洛谷等有防护的站点，练习时控制频率、仅取必要数据。
  • LLM 标注结果作为教学参考，课程判断以教师本人为准。
